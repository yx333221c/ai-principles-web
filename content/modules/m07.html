1950 年图灵设过一个门槛：到 2000 年，机器该让询问者聊五分钟后、认出它是机器的把握不到七成。七十六年后回看，门槛松得惊人。可今天的系统拆开只做一件事：用一堆数字加权平均另一堆数字。这点算术凭什么成了这几年 AI 最大的进展？

读这一段前，建议先看 M03（向量与点积）、M05（网络怎么学）与 M06（旧方法为什么记不住长句）。

把每个词元想成一张便签。模型读到第 7 个位置时，手里握着前 7 张便签。

注意力做的一件事，是给这 7 张便签分配注意力预算：这个位置该多参考第 3 张、少参考第 5 张，各分多少。分配完，按这个比例把便签上的内容加权混合成一份新摘要，作为当前位置的新表示。

「该给谁多分一点」不是人规定的，是模型从数据里学出来的。同一个句子，处理「它」这个位置时预算常流向它指代的名词；处理谓语时预算常流向主语——这是分析出来的偏好，不是写在代码里的规则。

这个类比对下面三件事不成立，务必记住：

  • 便签不是被人读的。便签上的内容是 嵌入，是 512 个左右的数字，没有任何一个位置对应「一个词」。
  • 预算不是一次分配的。真实模型每一层、每一个头都在独立重新分配预算。一个 32 层的模型对同一个位置做了上百次不同的「读便签」。
  • 没有「找到」这回事。便签堆里不存在一张被检索命中的便签：打分是两次投影之后的一次内积，连续、可部分、会随上下文整体漂移。把「检索」当成模型内部的事实，这个类比就失效了（机制段步骤条之后的那条「对下面几件事不成立」给了具体边界）。

钩子里那个门槛的方向值得多说一句：图灵 1950 年写的是「一台存储约 10⁹ 比特（按十进制 125 MB）的机器，能让平均询问者在五分钟询问后做对判断的概率不超过 70%」，也就是被骗率至少三成就算过关 存在争议——这是一道宽松的下限式门槛，既不是「必须完全骗不过」，也不是「误判率要压到 30% 以下」（那反而是更严格的要求）。至于今天的大模型是否算「通过了图灵测试」，两派并列：一派认为在受控的短交谈实验里，它被判为人类一方的比例已远超图灵的预期；另一派认为测试措辞含糊，且常被引用的 2014 年那次「通过」（Eugene Goostman 程序伪装成 13 岁乌克兰少年，五分钟交谈后说服了 30 位评委中的 33%）刚过图灵那条三成线，且靠的是「外国人英语不好」这种人格设定来解释怪异回答，不足以支撑结论 [2026-10]。本站不裁决，只强调一点：无论判「通过」与否，模型内部做的仍然是下面这套加权平均。原文见 Turing《Computing Machinery and Intelligence》（Mind 59, 1950）。

先记住一个事实：注意力是一张「临时生成」的查找表

普通权重是训练好就固定的。注意力最反直觉的地方在于：它每次前向传播都重新算一遍自己该用多少权重。权重不再是「参数」，而是「由当前输入决定的函数值」。这就是它能按需读取上下文的原因。

  1. 每个词元生成三个向量。同一份输入经过三组不同的固定权重，分别投影出查询 Q、键 K、值 V。这个分工只是说：Q 与 K 只出现在打分里，V 才是被搬进输出的那一份；三者都来自同一份输入，都由训练决定。
  2. 两两点积，得到分数矩阵。第 i 个位置的 Q 和第 j 个位置的 K 做点积，得到一个 n×n 的分数表 QKᵀ（n 是词元数）。分数大，只说明这两个投影方向对得齐——不是「命中」，也没有查表。
  3. 除以 √d，再按行做 softmax。把每行分数除以 √d（d 是 K 向量的维度）后做 softmax，把一行分数变成「加起来等于 1」的权重。softmax 负责「放大的更大、压小的更小」，让模型敢把预算集中到一两个位置。除以 √d 是为了防止分数太大把 softmax 推向 one-hot：那时权重对分数几乎不再敏感，Q/K 这条路就学不动了。
  4. 用权重对 V 加权求和。输出 = 权重 × 各位置的 V 相加。每个词元的新表示，就是它「按相关性读来的」上下文的加权平均。
  5. 套上因果掩码。训练目标是预测下一个词，所以位置 i 只允许看 ≤ i 的位置。做法是把 i < j 的分数设成 −∞，softmax 后权重正好是 0。要留意：这是自回归（只往后写、不许偷看未来）的要求，不是注意力本身的要求——编码器与 M11 的 ViT 用的就是双向版本，每个位置看所有位置。
  6. 多头：把维度切薄、并行多算几次。不是算一次 512 维注意力，而是算 8 次 64 维（本站沿用 Vaswani 等 2017 的 base 配置 [2026-10]），各自独立学，最后拼接再投影。于是不同头常常各有偏好：有的贴着上一个词，有的流向指代对象，有的跟着谓语。但「偏好」不等于「分工」，见下面这条。
  7. 残差与位置编码。注意力本身读不出顺序。在不用掩码时，打乱输入只是把输出的行一起打乱——这叫排列等变，注意不是「排列不变」。而一旦套上第 ⑤ 步的因果掩码，掩码按位置索引（j ≤ i）生效，打乱还会改变每个位置能看见哪些词，输出内容必然跟着变。所以顺序信息必须由位置编码显式提供：早期是加一张「位置向量表」（绝对位置编码，正弦版本的公式与频率设计见本节末尾的公式块），如今主流是RoPE，用旋转角度让点积天然带上「相距多远」。同时每个子层的输出都加回它的输入（残差连接）：一是让子层只需学「改动量」，二是给梯度留一条不经过任何权重的高速路。没有它，梯度要穿过整串子层连乘，随深度急剧衰减，深层反而训得更差——不是「传不回来」，而是传回来的已经被压平。
  8. 层归一化：把每个位置的向量自己拉平。层归一化（LayerNorm）算的是同一个词元内部那 512 个分量的均值与方差，沿特征维归一，不看别的词元、也不看整个批次。这正是它与批归一化的区别，也是它能用于变长序列、能逐位置独立生效的原因。归一化放在哪一段上是有分歧的：存在争议 原论文用的是后接式（子层输出先与输入相加，再归一化），梯度幅度随深度增长、要靠仔细的参数初始化与学习率预热才训得深；今天多数新模型用前接式（先归一化再进子层），梯度更平、更容易加深加大学习率，但若干消融报告称其最终质量略逊于调好的后接式。两派都没赢下全部证据 [2026-10]，本站两种都列出，不作裁决。
  9. 前馈网络：读完之后的逐位置加工。注意力只负责「把别的位置的内容搬过来」，搬来之后要有人处理它。这一步对每个位置独立做一次两层全连接：先升维到 4d，过一个激活函数，再降回 d。它不含任何跨位置运算，所以计算量随 n 线性增长（O(n·d²)），与注意力的 O(n²·d) 是两笔账。按原论文配置 d=512、dff=2048 推算：注意力四组投影共 4d²≈105 万参数，前馈两层共 2·d·dff≈210 万——一层里三分之二的关键参数在前馈，不在注意力。这也是「n 不够大时计算量并不由平方项主导」的原因。把两笔账按单位数摆一摆（每次乘加算一个单位）：注意力那张表的计算量是 2n²d，前馈是 2n·d·dff，两者相除得 n / dff——所以在 n = dff = 2048 处持平，序列比它短时前馈反而更贵（n=512 时注意力表只有前馈的四分之一）。若把注意力那四组投影（4n·d²）也算进注意力这一侧，持平点提前到 n = 2d = 1024。两种口径都说明同一件事：平方项要到几千词元才开始压过前馈。
  10. 键值缓存：为什么自回归解码可以只算一行。键值缓存（KV cache）成立的前提正是第 ⑤ 步的因果掩码：生成第 t 个词元时，它只需要「当前 Q 那一行 × 历史所有 K/V」，而历史词元的 K、V 一旦算出就不会再变（它们看不见未来）。于是每步从「重算整张 n×n 表」降到「算一行、追加两列」。代价是这块缓存必须常驻显存，且随上下文线性增长——那笔账 M10 第 ⑥ 步会算（每词元 128 KiB，128k 上下文 16 GiB）。它省的是算力，不是内存。

「查询 / 键 / 值」这套说法，对下面几件事不成立：

一，模型里没有真正的检索。没有符号匹配，没有命中判定，也没有「j 身上带着 i 要的那个东西」。分数只是 WQ、WK 投影之后的一次内积，同一对 (i, j) 在不同上下文、不同训练阶段会得到不同分数。

二，没有哪个头被指定管哪种关系。「这个头管指代、那个头管句法主语」几乎都是在模型外面统计出来、再回贴上去的事后归因。头之间高度冗余：训练后剪掉许多头，在同一任务的多数评测上几乎不掉分（Michel 等，2019 [2026-10]）——但只留 1–2 个头与一个都不留差别很大，换到别的任务上退化也会显现。

三，Q、K 不是「只有匹配、没有内容」。它们同样是同一份输入投影出来的，含语义信息；只是它们的乘积只进入打分，不直接进入输出。

把它当读代码时的地图用，别当模型里的事实用。

一个 Transformer 层的完整接线
主干 嵌入＋位置编码 → 多头注意力 → Add ＆ Norm → 前馈网络 → Add ＆ Norm → 下一层
原论文 x → 子层 ＋x→ 归一化 → 输出
今日主流 x → 归一化 → 子层 ＋x→ 输出
两段 Add ＆ Norm 就是第 ⑦⑧ 步；「前馈网络」是第 ⑨ 步；掩码在第 ⑤ 步。下方两格是同一条链的两种接法。
Attention(Q, K, V) = softmax(QK⊤√dk)V 「把每个位置的查询，和所有位置的键比一遍相似度，除以维度开根号做缩放，归一化成权重，再用权重把所有值加权求和。」

其中 Q ∈ [n × dk]、K ∈ [n × dk]、V ∈ [n × dv]，n 是词元数。维度必须写清，因为「Q 的列数要等于 K 的列数，softmax 之后的行数要等于 V 的行数」是读者最容易被卡住的地方。

sij′ = sij当 j ≤ i−∞当 j > i（不许看未来） 「第 i 个位置的查询想读第 j 个词元：j 在过去就放行（s 就是步骤 ② 算出的分数），j 在未来就设成 −∞。」exp(−∞) = 0，所以 softmax 之后未来位置的权重正好是 0——这就是步骤 ⑤ 的因果掩码。矩阵形式写出来是一个下三角可用的 n×n 表。反过来读它也提醒我们：掩码盯的是位置编号，不是词元的身份，所以打乱词元会改变每一行能看见谁。
FFN(x) = max(0, xW1 + b1) W2 + b2 「把这个位置的向量先乘一个升维矩阵、过一道取正的非线性，再乘一个降维矩阵加回来；每个位置各算各的，互相不看。」x 的形状是 [d]，W₁ 是 [d × 4d]，W₂ 是 [4d × d]，所以输出形状与输入一致，能直接走残差相加。
PE(pos, i) = sin(pos · 10000−2i/d)i 为偶数维cos(pos · 10000−2i/d)i 为奇数维（与 i−1 同频） 「给第 pos 个位置、第 i 对维度填一个正弦值，频率随 i 一路变慢。」分母从 1 涨到约 10⁴，所以不同维度的波长从 2π（约 6.3 个位置）一直拉到约 6 万个位置：每个维度是一把刻度不同的尺子，近处靠快尺分辨、远处靠慢尺分辨。这也解释了它为什么在超出训练时见过的距离之后失效：慢尺走到了从没被训练过的新刻度上，快尺却已经绕了许多圈、给出的相位与前面重复，两头的尺度一起失去可用信号。今天的模型多用 RoPE 或直接可学习的「位置向量表」，而不是这张正弦表。
LN(x) = γ ⊙ x − μ√σ² + ε + β 「把这一个词元自己的 d 个分量减掉它们的均值、除以它们的标准差，再逐维乘上学出来的缩放 γ、加上学出来的平移 β。」μ 与 σ² 只在同一个位置的各特征分量上求，不跨词元、也不跨批次——这就是第 ⑧ 步说的「沿特征维归一」。
展开：为什么要除以 √d，以及为什么在显式两两比较这一族里 O(n²) 难以回避

关于 √d。假设 Q、K 各分量是均值 0、方差 1 的独立随机变量，那么它们点积（dk 项相加）的方差是 dk，标准差约 √dk。不缩放的话，dk=64 时分数的标准差就是 √64 = 8：按这个正态假设，约三分之二的一行分数落在 ±8 之内（±1σ 概率 68.3%），而不是「普遍落在 ±8 之外」。真正的问题是极差：按 n 个正态样本的期望极差 2·E[max] 估算，一行 4 个分数就拉开约 2.06σ ≈ 16 个单位，一行 512 个能拉到约 6.1σ ≈ 49 个单位。softmax 是取指数再归一，差 16 个单位就意味着两边的权重差 e¹⁶ ≈ 890 万倍，几乎全部质量堆到最大那一项，权重对分数不再敏感，训练停滞。除以 √dk 把方差拉回 1。

已简化：这三条假设（独立、零均值、单位方差）只在初始化时近似成立；训练后 Q、K 的分量相关、方差也不再是 1，所以「点积方差 = d」是一个量级正确的启发式理由，而不是定理。原论文自己也只把它当作一种可能的解释。

关于平方复杂度。注意力要显式建立「每对位置之间的关系」，n 个位置的两两组合就是 n²。词元从 4k 涨到 128k（32 倍），训练与 prefill 阶段要摆整张 n×n 分数表，算力与显存就是 32²=1024 倍。但增量解码不必摆整表：每一步只算当前那一行（第 ⑩ 步的键值缓存），这时真正随上下文线性增长的是缓存，不是那张表（M10 第 ⑥ 步）——两笔账别混。还要留意「平方」只是注意力那一部分：同层的前馈是 O(n·d²)，随 n 线性（第 ⑨ 步）。

至于平方是否必然：存在争议 一派认为只要想要「每个位置都与全上下文建立联系」，两两比较的代价就绕不开，工业界的滑窗、分块、键值缓存都只是在常数与显存上做文章；另一派（线性注意力、状态空间模型、检索式稀疏）主张不做全对比较也能行，代价是要引入近似、额外的召回机制或在长距离精确检索上让步 [2026-10]。本站把两种立场并列，不裁决。

它到底在看哪里

下面这张矩阵就是第 ③ 步的产物： softmax 之后的权重，每行相加等于 1。真实大模型的注意力矩阵有几百行几百列，这里用一个 9 词元的短句、4 个头演示同一件事。
「注意力权重就是模型思考的过程，看它看哪里就知道它在想什么。」

为何会有这个误解：太多文章把热力图当「可解释性」卖，因为「模型看这个位置是因为那个位置」听起来正好回答了「为什么」。加上「查询 / 键 / 值」这套检索词汇本身就在暗示「它在找理由」。

正确说法：注意力权重只告诉你「这一层这个头的输出被哪些位置的 V 影响了」，它是计算路径，不是理由。经过几十层混合与残差之后，最终输出与某个高权重位置之间的因果关系早已被反复改写；同一句话换个头、换个层，热力图会完全不同。它可以当线索，不能当解释。

「Transformer 能处理长文本，是因为它有一个能装下整篇文章的记忆模块。」

为何会有这个误解：RNN 时代「隐藏状态 = 记忆」的说法太牢固，人们自然以为 Transformer 也有个更大的同类。

正确说法：Transformer 没有独立的记忆模块。它的「记忆」就是上下文本身 + 权重矩阵里的参数。所谓窗口长度，指的是这一次前向传播里同时摆着多少个词元；窗口外的内容不是「忘了」，而是根本没被计算。这也解释了为什么把同样的话换个顺序放进上下文，答案可能变化——第 ⑤ 步的掩码是按位置编号生效的，顺序一变，每个位置能看见的集合就变了。

「多头注意力就是多个模型投票，取多数意见。」

为何会有这个误解：「头」让人联想到「多个视角再综合」，投票是日常里最熟悉的综合方式；而「每个头负责一种语法关系」这类说法又给「各投一票」提供了看似合理的脚本。

正确说法：头不是投票，而是把一次昂贵的全维度比较拆成几次便宜的窄维度比较，各学一种加权方式，最后把所有头的输出拼接起来再做一次线性投影——是一次求和，不是几次表决。没有任何环节在做「多数决」。实践中许多注意力头接近休眠：训练后剪掉它们，在同一任务的多数评测上几乎不掉分（Michel 等，2019 [2026-10]）——但只留 1–2 个头与一个都不留差别很大，换到别的任务或微调场景上，退化也会显现，所以「既然能剪就说明头不重要」是过度外推。
注意力不是理解，是每次前向都重新算一遍的加权平均。

顺序信息也来自数据规模之外的东西：它是第 ⑦ 步那样被显式设计进模型的（位置编码、掩码的位置索引），不是从更多词元里自己长出来的。带着这句去 M08。

自测：把输入的 5 个词元顺序打乱，其他什么都不改。注意力的输出会怎样？

再想一步：注意力分数确实只由 Q 与 K 的点积决定，点积不知道「第 3 个」是什么意思——所以不加掩码时，打乱输入只是把输出的行一起打乱，这叫排列等变（不是排列不变：每一行的内容跟着走）。但第 ⑤ 步的因果掩码是按位置编号（j ≤ i）施加的：原来排在第 1 位的词元被打到第 4 位，它现在能看见的是第 1–4 位，而原来只有第 1 位——可见集合变了，这一行的加权平均自然跟着变。掩码也不会让计算「失败」，它只是限制谁可见。

对了。这正是机制拆解第 ⑦ 步的全部要点：注意力本身是排列等变的，顺序必须由位置编码额外提供，而掩码本身还额外引入了对位置编号的依赖。RoPE 之所以成为主流，就是因为它把顺序编码进旋转角度，让点积天然读出「相距多远」。带着这个结论去 M08：顺序信息也来自数据规模之外的东西。

## 争议译名（并列标注原词）

- **涌现能力 / emergent ability**：中文技术圈尚无统一定义，写作时保留英文原词并加 `badge--debate`。
- **对齐 / alignment**：与「一致性（consistency）」常混用；本站 `alignment` 一律译「对齐」。

## 缩写使用规则

1. 缩写（RLHF / RAG / DPO / KV cache）首次出现必须展开：`基于人类反馈的强化学习（RLHF）`。
2. 展开后可在同段内使用缩写；跨模块需重新展开。
3. 正文不使用 `<abbr>` 之外的自造缩写（不许出现「注」「预注」这类）。
